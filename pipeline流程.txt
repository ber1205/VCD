1. 多人对白交叠（Crosstalk / Overlapping Speech）分轨处理
*盲点：影视剧中经常出现“角色 A 在说台词的同时，角色 B 突然插嘴/惊呼”。Qwen-ASR 会识别出时间轴重叠（$start_B < end_A$）。如果按单音轨合成，后置混音会发生声音冲撞。
*优化：在 stage-tts 与混音阶段引入 多音轨图层（Track Layering）：
·时间轴重叠的 Dialogue Turn 被标记为 Track_0 与 Track_1。
·两个角色分别生成独立 WAV，在 Rust-Wasm 混音时按双音轨并发叠加，并为被插嘴的声音做微弱的低通滤波（Low-pass Filter）让位。
2. Scene 跨块拼接处的“零交叉点爆音”（Pop/Click Noise at Scene Boundary）
*盲点：利用 Cloudflare R2 Multipart Concatenation 拼接 Scene01.wav 和 Scene02.wav 时，音频波形在切口处若未处于零交叉点（Zero-Crossing），播放时会产生明显的“咔哒”爆音，BGM 也会出现瞬时断层。
*优化：·在 Rust-Wasm 的 Scene Master 阶段引入 $50\text{ms}$ 等功率 S 型交叉淡化（Equal-Power Crossfade）：Scene 尾部最后 $50\text{ms}$ 做 Fade-out，下一个 Scene 头部前 $50\text{ms}$ 做 Fade-in。3. 低于 3 秒的小配角/群众演员“声纹污染防护”
*盲点：某个只有 1~2 句台词的群众演员（如路人喊“闪开！”），提取出的纯净音频不足 $3.0\text{s}$。CosyVoice 在极短 audio prompt 下容易出现音色漂移或电音化。
*优化：在 Stage 3（声纹分级）增加短音频保底机制：若有效音频长度 $< 3.0\text{s}$，系统不启动 Zero-shot 复刻，而是将角色音色硬匹配至预设的高品质静态音色库（Stock Voice Embeddings），仅继承原声的语速与 Pitch，防止 API 生成废音。
4. 60 分钟生命周期（TTL）自动垃圾回收（R2 Lifecycle + DO Alarm）
*盲点：频繁写入临时分离音轨会导致 R2 存储与 D1 写入成本增加。
*优化：配置 Cloudflare R2 Lifecycle Rule，将前缀为 scratchpad/ 的文件统一设为 1 天自动物理销毁；同时在 Durable Object 中设置 this.ctx.storage.setAlarm(Date.now() + 3600 * 1000)，处理完成后 60 分钟自动清理 D1 历史状态。
